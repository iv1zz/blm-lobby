# BLM Lobby 3D

Interactive 3D model of the lobby (block A1, 1st floor). Opens in any browser.

- `index.html` — current version (v4)
- `v4/` — version 4: functional fit-out (reception, security, check-in, luggage, valuables), SketchUp files
- `v3/` — frozen version 3: plan as built plus agreed partitions

Plan dimensions follow the 1:50 drawing. Heights and the outdoor layout (parking, barrier) are assumed.
