# BLM Lobby 3D

Interactive 3D model of block A1. Opens in any browser.

- `index.html` — current version (v6): floor 1 lobby after the designer's renders, floor 2 spa
- `v6/` — version 6: viewer with a colour palette slider, SketchUp files (`.rb`, `.dae`), plans (PDF A3 1:50, DXF per floor)
- `v5/` — frozen version 5: lobby plus the first spa layout
- `src/` — model sources and build script; see `CLAUDE.md`
- `v4/` — frozen version 4: lobby fit-out (reception, security, luggage, waiting zone)
- `v3/` — frozen version 3: plan as built plus agreed partitions

Plan dimensions follow the 1:50 drawing. Heights and the outdoor layout (parking, barrier) are assumed.
